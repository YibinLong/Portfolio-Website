I was inspired by this [tweet](https://x.com/tobi/status/1909231499448401946) from Tobi Lütke, CEO of Shopify, a few months back.

Tobi states that using AI is now a core expectation at Shopify. After this, you don't have to hide that you're using AI, hoping that your boss wasn't looking.

This post feels like a turning point in tech where AI usage went from something that had to be hidden away to something that was openly allowed, and even expected. Before, I had the sense when I was using LLMs to write code that I was "cheating". I no longer feel that way.

AI coding is now fully mainstream and widely accepted. It’s getting hard to deny that a strong AI engineer can now do the work that used to require a full software team. The real variable is how willing a developer is to accept that shift, and how willing they are to learn the tech.

> "If you’re not using AI reflexively in your work, you’re falling behind."
