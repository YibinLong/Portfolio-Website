I was inspired by this [tweet](https://x.com/tobi/status/1909231499448401946) from Tobi Lütke, CEO of Shopify, a few months back.

Tobi states that using AI is now a core expectation at Shopify. You don't have to hide using AI away from your boss, hoping that they weren't looking. It's not "cheating" to use AI. Trying to code without using AI is the same as being a Luddite that shunned the invention of the loom 200 years ago.

I like this post because it seems like a watershed moment (FIX) in tech where AI usage went from something that had to be hidden, to something that was graciously allowed, and even expected. Before, I had the sense when I was using LLMs to write code that I was "cheating", that I would have been much better to write it all by hand, and that I would be seriously hampering my learning.

It's a watershed moment because it brings using AI from a belief of shame - that we should be hiding away in our little corners that we're using it, else other purist programmers judge us for not writing code manually.

We no longer have to feel ashamed of using AI, and I no longer feel ashamed of using AI. If the CEO of the biggest tech company in Canada allows it, why can't I? It resembles the [Apple ad](https://www.youtube.com/watch?v=VtvjbmoDx-I), where it's okay to code with AI now.

-> my thoughts: basically using ai in coding has gone MAINSTREAM ACCEPTANCE now, instead of colloquially disdained / looked down upon.



2. AI Is Now a Core Expectation
Using AI effectively is no longer optional at Shopify. It’s now a baseline performance expectation for everyone — from leadership to individual contributors. If you’re not using AI reflexively in your work, you’re falling behind.

3. AI as a Skill and Multiplier

Learning to use AI well is a skill that requires practice, not just occasional experimentation.

AI acts as a force multiplier, letting top performers achieve “100×” outcomes.

Employees are encouraged to treat AI like a pair programmer, researcher, critic, or tutor.
